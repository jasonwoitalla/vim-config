# Neovim configuration

The keybindings and editor settings live in [`init.lua`](init.lua).

To carry the same muscle memory into other editors, see:

- [IntelliJ IDEA + IdeaVim](external-keymaps/intellij/README.md)
- [VS Code + VSCodeVim](external-keymaps/vscode/README.md)
- [Shared keybinding reference and compatibility notes](external-keymaps/README.md)

These setups use native IDE features wherever possible. They do not load the
Neovim configuration or require its plugins.
